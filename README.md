# Reader — минималистичная читалка в стиле iOS 26

Простой статический сайт для чтения одной FB2-книги.
Стиль: iOS 26 — Liquid Glass, SF Pro, светлая/тёмная тема.

## Структура

```
.
├── index.html
├── assets/
│   ├── css/style.css
│   └── js/app.js
├── books/
│   └── book.fb2        ← положи свою книгу сюда (имя именно book.fb2)
├── .nojekyll
└── README.md
```

## Куда положить книгу

1. Кинь FB2-файл в папку `books/`.
2. Назови его **`book.fb2`** (либо `book.fb2.zip` — сжатый вариант тоже поддерживается).

Сайт сам прочитает из файла:
- название книги
- автора
- обложку (если есть)
- структуру глав

Поэтому ничего вручную править не нужно.

## Что поддерживается

- **`.fb2`** — обычные FB2-файлы (UTF-8, Windows-1251 и др. — кодировка определяется автоматически)
- **`.fb2.zip`** — упакованные в zip (распаковка прямо в браузере через JSZip)
- Изображения и обложка из FB2
- Главы (секции), эпиграфы, стихи, цитаты, заголовки разных уровней

## Локальный запуск

`fetch()` не работает с `file://`, поэтому просто открыть `index.html` двойным кликом не получится.
Запусти любой статический сервер:

```bash
# через python
python -m http.server 8080

# или через npx
npx serve .
```

Открой http://localhost:8080.

## Деплой на GitHub Pages

1. Создай новый репозиторий на GitHub (например, `reader`).
2. В этой папке:

   ```bash
   git init
   git add .
   git commit -m "init: minimal iOS 26 reader (FB2)"
   git branch -M main
   git remote add origin https://github.com/<твой-username>/<имя-репо>.git
   git push -u origin main
   ```

3. На GitHub: **Settings → Pages**
   - **Source:** Deploy from a branch
   - **Branch:** `main` / `/ (root)`
   - Save.

4. Через ~1 минуту сайт будет доступен по адресу:
   `https://<твой-username>.github.io/<имя-репо>/`

> Файл `.nojekyll` уже добавлен — он отключает Jekyll, чтобы папки/файлы корректно отдавались.

## Управление

- **← / →** или **PageUp / PageDown** — предыдущая / следующая глава
- **Home / End** — в начало / конец книги
- **Свайп влево/вправо** — навигация по главам на телефоне
- **Иконка солнца/луны** — переключение темы
- Прогресс чтения (позиция скролла) и тема сохраняются в браузере

## Где взять FB2

Книги в формате FB2 можно купить, например, на:
- ЛитРес — https://www.litres.ru
- Bookmate — https://bookmate.com
- Альпина — https://alpinabook.ru

После покупки файл скачивается напрямую — просто переименуй в `book.fb2` и положи в папку `books/`.
